Which app is this?

The name goes on the launcher, the task switcher and the splash. The URL is what opens on launch.

Shown under the icon on the device. Keep it short.

From Power Apps → Share, or the address bar while the app is running. It must be the /play/ link, not the editor.

Test the link first. Open it in a private browser window. If it asks for a sign-in you can complete, the shell will too, as long as every host it reaches is in the next step.

How should the device behave?

These map to Android activity flags, not to anything the operator can change.

The scan tool must broadcast this exact string. Set the same value in DataWedge.

Zebra's key is the default. The receiver also falls back to data and version_1_data, so Honeywell and Datalogic usually work unchanged.

Keyboard-wedge mode is not used. The shell reads a broadcast intent, which is why held keys, dropped characters and focus jumps do not happen.

What may the app reach?

One host per line. Subdomains are included automatically. Everything else is blocked and logged as [SECURITY][BLOCKED].

Paste the scheme or a full URL and it is reduced to the host. Add every host your app or its sign-in flow visits.

The shipped list is Microsoft's minimum, not a promise. Personal Microsoft accounts sign in through login.live.com, and some tenants pull assets from azureedge.net, azurefd.net, graph.microsoft.com or azure-apim.net. A blocked host shows up in logcat, not as a crash.
